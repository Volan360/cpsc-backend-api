## OpenAPI-First Workflow

All API changes start in `openapi.yaml`. Never manually create or edit files in `build/generated/`.

1. **Edit** `src/main/resources/openapi.yaml`
2. **Generate** interfaces and models:
   ```powershell
   .\gradlew.bat openApiGenerate
   ```
3. **Implement** the new or changed method in the appropriate controller (they `implement` a generated interface)
4. **Build and test:**
   ```powershell
   .\gradlew.bat clean build
   ```

### What gets generated

| Output | Location |
|--------|----------|
| API interfaces (one per tag) | `build/generated/.../api/` |
| Model classes | `build/generated/.../model/` |

Controllers must implement the generated interface — the compiler enforces that all operations are implemented and that request/response types match the spec.

### Common generation issues
- YAML syntax errors: validate at [editor.swagger.io](https://editor.swagger.io/)
- Missing `operationId` on a new path/method: add one before generating
- After adding a new endpoint: implement the method in the matching controller or the build will fail with a `not implemented` compile error

## Security Configuration

### JWT Authentication

The `JwtAuthenticationFilter` validates every request to protected endpoints:
1. Extracts the JWT from `Authorization: Bearer <token>`
2. Validates signature and expiry against the Cognito User Pool's JWK endpoint
3. Extracts the `sub` claim and sets it as the authenticated principal
4. Controllers retrieve the user ID via `SecurityContextHolder.getContext().getAuthentication().getName()`

### Public vs Protected

**Public endpoints** (no token required):
- `GET /api/hello`
- `POST /api/auth/signup`
- `POST /api/auth/confirm`
- `POST /api/auth/resend-code`
- `POST /api/auth/forgot-password`
- `POST /api/auth/confirm-forgot-password`
- `POST /api/auth/login`
- `GET /swagger-ui/**`
- `GET /api-docs/**`

**Protected:** everything else — requires a valid JWT in the `Authorization` header.

**Which token:**
- ID Token for all resource endpoints (Institutions, Transactions, Goals, Analytics)
- Access Token for `/api/secure/*` (calls Cognito user management APIs server-side)

### CORS

Configured in `SecurityConfig.corsConfigurationSource()`. Allowed origins:
- `http://localhost:4200` and `http://localhost:3000` (local dev)
- `https://app-devl.fullstackcashtrack.com`
- `https://app-acpt.fullstackcashtrack.com`
- `https://www.fullstackcashtrack.com`
- `https://fullstackcashtrack.com`

All HTTP methods and headers permitted. Credentials (`Authorization` header) are allowed.

## Postman Collection

`CPSC_Backend_API.postman_collection.json` — import into Postman for pre-configured testing.

### Setup
1. Import the collection file into Postman
2. Create a Postman environment with variable `baseUrl`:
   - Local: `http://localhost:8080`
   - devl: `https://devl.fullstackcashtrack.com`
   - acpt: `https://acpt.fullstackcashtrack.com`
   - prod: `https://prod.fullstackcashtrack.com`

### Token Management
The **Login** request includes a test script that automatically saves `idToken`, `accessToken`, and `refreshToken` to environment variables. All subsequent protected requests use `Bearer {{idToken}}` or `Bearer {{accessToken}}` automatically.

### Collection Structure

| Folder | Requests |
|--------|----------|
| Authentication | Sign Up, Confirm Sign Up, Resend Verification Code, Forgot Password, Confirm Forgot Password, Login |
| Protected Endpoints | Get Profile, Update Screen Name, Delete Account |
| Institutions | Create, Get, Edit, Delete |
| Transactions | Create, Get, Update, Delete |
| Goals | Create, Get, Edit, Delete, Complete Goal |
| Analytics | Generate (×6 types), Get Health Score (×2), Generate Report (×6 types) |
| Public Endpoints | Hello |
